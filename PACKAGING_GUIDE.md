# Packaging Guide

This guide explains how to prepare and distribute this educational repository.

## What to Include

### Always Include
✅ Source code (`src/` directory)
✅ Notebooks (`notebooks/` directory)  
✅ Documentation (`README.md`, `STUDENT_GUIDE.md`, `docs/`)
✅ Environment specification (`environment.yml`)
✅ Directory structure (empty directories with `.gitkeep` or README files)
✅ `.gitignore` file

### Never Include
❌ Model files (`models/*.xml`) - too large, license restrictions
❌ Results files (`results/`) - generated by students
❌ Experimental data (`data/experimental/`) - potentially sensitive
❌ Python cache (`__pycache__/`, `.ipynb_checkpoints/`)
❌ Environment directories (`venv/`, `env/`)

### Optionally Include
⚠️ Example model (if small and openly licensed)
⚠️ Example experimental data (if fabricated/public domain)
⚠️ Completed notebook outputs (for reference)

## Creating a Distribution Package

### Method 1: Git Repository (Recommended)

```bash
# Initialize git repository
git init
git add .
git commit -m "Initial commit: Metabolic modeling education repository"

# Create GitHub repository and push
git remote add origin <your-github-url>
git push -u origin main
```

**Advantages:**
- Version control
- Easy updates
- Collaborative development
- Issue tracking

### Method 2: ZIP Archive

```bash
# Create a clean copy
cd /path/to/metabolic-modeling-education
git clean -fdx  # Remove all untracked files (careful!)

# Create ZIP (Unix/Mac)
zip -r metabolic-modeling-education.zip . -x "*.pyc" -x "__pycache__/*" -x ".git/*"

# Create ZIP (Windows)
# Use 7-Zip or WinRAR to compress, exclude:
# - __pycache__ directories
# - .pyc files
# - .ipynb_checkpoints
# - Large model files
```

### Method 3: Platform-Specific Distribution

**For LMS (Canvas, Blackboard, Moodle)**:
1. Create ZIP as above
2. Include a `INSTALLATION.md` with step-by-step conda setup
3. Upload to course resources
4. Provide video walkthrough

**For GitHub Classroom**:
1. Create template repository
2. Students fork and clone
3. Automatic setup checks
4. Easy submission

**For Docker** (Advanced):
Create a `Dockerfile`:
```dockerfile
FROM continuumio/miniconda3
COPY environment.yml /tmp/
RUN conda env create -f /tmp/environment.yml
COPY . /workspace
WORKDIR /workspace
CMD ["jupyter", "notebook", "--ip=0.0.0.0", "--allow-root"]
```

## Verifying the Package

### Checklist Before Distribution

- [ ] All notebooks run without errors
- [ ] All imports work correctly
- [ ] Documentation is up-to-date
- [ ] Example model is included (or instructions to download)
- [ ] `environment.yml` is tested on clean system
- [ ] File paths use relative paths (no absolute paths!)
- [ ] No personal data or credentials included
- [ ] License file included (if applicable)

### Test Installation

```bash
# Extract package
unzip metabolic-modeling-education.zip
cd metabolic-modeling-education

# Create environment
conda env create -f environment.yml
conda activate metabolic-modeling

# Test notebooks
jupyter notebook
# Manually run each notebook start-to-finish
```

## File Size Considerations

### Typical Sizes
- Source code (`src/`): ~50 KB
- Notebooks (empty): ~100 KB
- Documentation: ~50 KB
- **Total (without models/data)**: ~200 KB

### With Optional Content
- Small model (E. coli): ~5 MB
- Notebook outputs (executed): ~500 KB
- Example data: ~100 KB
- **Total (with examples)**: ~6 MB

### Recommendations
- **Git repository**: Don't include large files
- **ZIP for students**: Include small example model
- **Docker**: Can include everything (self-contained)

## Quality Assurance

### Before Each Release

1. **Code Review**
   - All functions have docstrings
   - Type hints are correct
   - No hardcoded paths

2. **Documentation Review**
   - All links work
   - Consistent formatting
   - Up-to-date screenshots

3. **Testing**
   - Run all notebooks

   - Test with fresh environment

4. **Feedback Integration**
   - Address previous semester's issues
   - Update based on student feedback
   - Improve unclear sections

## Troubleshooting Distribution Issues

### Common Problems

**"Students can't download the repository"**
→ Check file size, provide mirror, use institutional server

**"Environment installation fails"**
→ Test on multiple platforms, provide fallback instructions

**"Notebooks don't run"**
→ Include output in example notebooks, provide Docker alternative

**"Can't find model files"**
→ Include download instructions, host small model
