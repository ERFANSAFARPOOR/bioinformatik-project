📚 Project Overview

This repository provides a complete, beginner-friendly introduction to genome-scale metabolic modeling using COBRApy. Students progress through three educational notebooks, learning to load models, run simulations, identify essential genes, and validate predictions against experimental data.

📓 Educational Notebooks

1

Basic Flux Balance Analysis

⏱️ 45-60 minutes

Learning Objectives:

  • Load and explore genome-scale metabolic models
  • Understand model components (reactions, metabolites, genes)
  • Run FBA simulations to predict growth rates
  • Visualize metabolic flux distributions
  • Interpret exchange reactions (uptake/secretion)

Key Concepts: SBML format, steady-state assumption, biomass reaction, optimization

2

Gene Essentiality Analysis

⏱️ 45-60 minutes

Learning Objectives:

  • Understand what makes a gene essential
  • Perform computational gene knockout experiments
  • Classify genes based on growth phenotype
  • Analyze essentiality statistics and distributions
  • Save results for further analysis

Key Concepts: Gene-Protein-Reaction associations, single gene deletion, essentiality thresholds

3

Experimental Validation

⏱️ 45-60 minutes

Learning Objectives:

  • Compare computational predictions with experimental data
  • Calculate validation metrics (precision, recall, accuracy)
  • Visualize agreement and discrepancies with Venn diagrams
  • Understand sources of prediction errors
  • Interpret model limitations and areas for improvement

Key Concepts: Model validation, confusion matrix, false positives/negatives, F1 score
