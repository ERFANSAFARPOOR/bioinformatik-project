# Models Directory

This directory contains the SBML models used in our project.  
The focus of this repository is **Pseudomonas aeruginosa**, and we use a single curated genome-scale metabolic model for all analyses.

## Primary Model

### **Pseudomonas aeruginosa (Genome-Scale Metabolic Model)**
- **Model:** MODEL1507180020 (or iPae1146 if using the BiGG version)
- **Organism:** *Pseudomonas aeruginosa*
- **Description:**  
  A well-curated pathogen model frequently used in studies of metabolic capabilities, essential genes, and environmental responses.
- **Typical scale:** ~1100 genes, ~1100–1500 reactions (depending on the variant)
